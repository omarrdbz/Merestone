## Objective and risk

Verify the use of evaluation probes and detectors.
A detector label without effect/rubric is accepted as a finding, or execution context is lost.

Controls: CTL-EVALUATION

## Applicability

One alternative must be satisfied: automated_scanner

Actor: Actor with access to an isolated scanner configured for an authorized endpoint, limited to the authorized environment.

Access: gray-box; access limitations are recorded without inferring PASS

## Preparation

- Isolated scanner configured for an authorized endpoint; small corpus; version and budget fixed
- Current charter, limits and telemetry defined.

Allowed baseline: Equivalent operation on an allowed fixture, with a documented expected result.

Restricted control: Restricted operation without an adversarial technique; document the control's decision.

## Procedure

1. Freeze versions, state and policy; run the allowed baseline.
2. List the probes/detectors of the installed version and select the relevant ones.
3. Run the baseline and a bounded campaign, keeping inputs, outputs, detector and cost.
4. Manually review positive/negative samples against the case oracle and export evidence.
5. Keep traces, restore fixtures and check queues/residual state.
